Engineering Architecture

How Haven C++ Hits Cloud Speeds in Pure C++20

Zero Python wrappers, zero per-layer PCIe ping-pong, and zero framework bloat. Every matrix tile, collective, KV buffer, and sampler path is engineered directly for bare-metal silicon.

Model-General Compiler

Multi-Architecture StableHLO Engine

Compiles dense and sparse MoE transformers directly from ModelConfig + GGUF tensors (Gemma 4/3/2, Llama 3/4, Qwen 2.5/3, Mistral, Phi-3/4, Ava 26B-A4B MoE) into persistent HBM3 executables — CI-verified across 260 multi-arch graphs on Linux GCC & Windows MSVC.

Multi-Tenant Continuous Batching

Async Per-Slot pos_vec[B] & Scheduler

Lock-free TpuContinuousBatchScheduler multiplexes up to 128 concurrent HTTP/SSE clients into shared HBM3 KV slots with in-place stablehlo.scatter decode and slot-targeted S=128/32/16/8/1 prefill — verified 6/6 zero cross-slot leakage on v6e-4.

Zero-Pad HBM3

TPU (8,128)-Aligned Donated KV Cache

Stores KV tensors as [N_kv, B, Hkv_sh, T, HD] with tf.aliasing_output in-place HBM3 buffer donation — eliminating 4x–8x TPU sublane padding overhead and fitting 128 concurrent 2048-token streams cleanly inside HBM3.

30.6× Lower H2D

On-Chip Sharded Embedding Gather

Uploads only [B, S] int32 token IDs (4 bytes for B=1, 512 bytes for B=128), cutting H2D transfer time from 2.76 ms to 0.09 ms. Reuses tied sharded %w_lm_head with zero extra HBM3 bytes.

150× Faster Sampling

Top-Tail 262k Sampler & AVX2/F16C SIMD

Replaced full-vocab 262k sorting with top-tail cutoff + std::partial_sort (22.6 ms → 0.15 ms/tok) and vectorized local CPU GEMV kernels to 34.81 GFLOPS (3.64× speedup) for seamless non-TPU execution.

Sovereign Ecosystem

64-Bit .hmb Memory, 17 Plugins & C ABI

Contiguous binary memory vault (100,000 memories in 71.3 MB, 9.86 ms global AVX2 scan, 1.27 µs active recall), 17 zero-boot-RAM lazy plugins, Pathways async scheduler (1.11M+ tasks/s), and universal C ABI for C# P/Invoke and Android JNI.

Zero-Trust Hardening

Audited Cryptography, Sandboxing & Fuzz Defense

Hardened for both sovereign local desktops and multi-node production clusters, verified continuously with automated cryptographic KATs, live wire attack simulations, and 400-mutant binary/JSON fuzzing (0 ASan/UBSan findings).

SHCP v2 Wire Security

HMAC-SHA256 + ChaCha20-Poly1305 AEAD

Cluster nodes enforce 256-bit zero-trust pairing tokens, mutual challenge-response authentication, RFC 8439 AEAD wire encryption, strict monotonic anti-replay counters, and immediate severing on tampering or plaintext downgrade attempts.

HTTP & SSE Guardrails

Loopback-Default Server & Disconnect Abort

Binds strictly to 127.0.0.1 by default with DNS-rebinding Host verification, loopback-only CORS/CSRF enforcement, optional constant-time Bearer --api-key auth, Slowloris timeouts, canonical path containment, and instant non-blocking client-disconnect cancellation.

Terminal execution runs inside Win32 Job Objects / POSIX rlimit sandboxes; browser plugins block private-IP DNS-SSRF; custom RFC 8259 JSON, GGUF v3, and .hmb parsers pass 400 adversarial fuzz mutants with zero crashes.

Build & Deploy

Quick Start

Compiles in seconds with CMake, Ninja, and any C++20 compiler on Windows, Linux, or Google Cloud TPU VMs. Automatically falls back to AVX2 CPU when no TPU is present.

bash — build, serve & verify 
# 1. Clone and build (Windows, Linux, or Cloud TPU VM)
git clone https://github.com/ssfdre38/haven-cpp.git
cd haven-cpp
cmake -B build -G "Ninja" -DCMAKE_BUILD_TYPE=Release
cmake --build build -j $(nproc)

# 2. Serve single-user interactive (248.3 tok/s) OR multi-tenant continuous batching (2,198 tok/s live SSE)
./build/haven-server --port 11436 --model /tmp/haven-chat-v5.0.gguf --tpu --tpu-int8 --tpu-batch 64 --tpu-argmax

# 3. Or run locally on CPU (loopback-guarded by default)
./build/haven-server --port 11436 --model haven-chat-v5.0.gguf

# 4. Run full Cloud TPU parity + B=1..128 suite (or --emit-only-synthetic offline on any CPU, zero GGUF)
./build/test-tpu-gemma4-onchip --emit-only-synthetic && ./build/test-tpu-scheduler

# 5. Verify all 6 adversarial crypto KAT, SHCP v2 attack, and 400-mutant fuzz suites
./build/test-security-fuzz && ./build/test-secure-cluster
